# 04. Data Dictionary

Synthetic export modelled on HubSpot's standard objects and internal property names. Generated by [src/generate_data.py](../src/generate_data.py).

## companies.csv

| Column | Meaning |
|---|---|
| company_id | Record ID |
| name | Company name |
| domain | Company domain name |
| plan | Ferncast plan: free, creator, pro, business, enterprise |
| country | Country (blank for some records) |
| owner_id | Company owner (sales rep) |
| created_at | Create date |

## contacts.csv

| Column | Meaning |
|---|---|
| contact_id | Record ID |
| company_id | Associated company (blank if not associated) |
| first_name, last_name, email | Contact details |
| lifecycle_stage | subscriber, lead, marketingqualifiedlead, salesqualifiedlead, opportunity, customer |
| lead_source | Original source of the contact |
| owner_id | Contact owner |
| country | Copied from the company |
| created_at | Create date |
| became_mql_at | Date the contact became an MQL |
| first_contacted_at | First logged sales touch after becoming an MQL |

## deals.csv

| Column | Meaning |
|---|---|
| deal_id | Record ID |
| company_id | Associated company |
| dealstage | appointmentscheduled, qualifiedtobuy, presentationscheduled, contractsent, closedwon, closedlost |
| amount | Annual contract value in USD (blank for some deals) |
| createdate, closedate | Create date and expected close date |
| last_activity_at | Last logged activity |
| owner_id | Deal owner |

## workspaces.csv

| Column | Meaning |
|---|---|
| workspace_id | Product workspace ID |
| company_id | Company the workspace belongs to |
| plan | Self-serve plan: free, creator, pro |
| active_users_30d | Users active in the last 30 days |
| recordings_30d | Recordings created in the last 30 days |
| invites_sent_30d | Teammate invites sent in the last 30 days |
